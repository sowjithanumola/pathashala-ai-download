# Pathshala AI — Android Download Website

A responsive, Gen Z-inspired landing page for the Android APK release of Pathshala AI.

**Tagline:** Learn anything. In any language. Anywhere.

## What's included
- Single-page responsive landing site
- Android-only download messaging
- Ten confirmed Pathshala AI modules
- Illustrative preview cards (not real app screenshots)
- Download button that fetches the APK asset from the latest GitHub Release

## Deploy on Vercel
Import this repository into Vercel. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.

## Publish the APK
Create a GitHub Release and attach the signed APK with the exact filename:

`PathshalaAI.apk`

The download button in `index.html` points to:

`https://github.com/sowjithanumola/pathashala-ai-download/releases/latest/download/PathshalaAI.apk`

Once the release includes an asset with that exact filename, the button downloads it directly.

## Important
- The APK is not included in the text-only repository commit.
- Replace illustrative preview cards with real Android app screenshots before claiming they are actual screenshots.
- Only distribute an APK you own or have permission to distribute.
